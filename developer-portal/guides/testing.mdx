Mobile Money provides a robust sandbox environment allowing you to test your integration without moving real money or interacting with live mobile money networks.

## Environments

| Environment | Base URL | Description |
| :--- | :--- | :--- |
| **Sandbox** | `https://sandbox-api.mobilemoney.dev` | Simulated environment for development. |
| **Production** | `https://api.mobilemoney.dev` | Live environment with real funds. |

<Info>
API keys are environment-specific. A sandbox API key will not work in production, and vice versa.
</Info>

## Test Credentials & Phone Numbers

In the Sandbox environment, magic phone numbers dictate the outcome of a transaction. Use these numbers to simulate different scenarios.

| Phone Number | Expected Outcome | Scenario Simulated |
| :--- | :--- | :--- |
| `+254000000000` | Success | Normal successful transaction |
| `+254000000001` | Failure | Insufficient Funds |
| `+254000000002` | Failure | User cancelled USSD prompt |
| `+254000000003` | Timeout | User did not respond in time |
| `+254000000004` | Error | Provider network offline |

## Simulating Transactions

When you initiate a deposit with `+254000000000`, the sandbox will automatically progress the state machine from `pending` to `processing` to `completed` over the course of about 10 seconds, and emit the corresponding webhooks.

## Webhook Testing

We recommend using tools like [ngrok](https://ngrok.com/) to expose your local development server to the internet so you can receive webhooks from the Bridge sandbox.

1. Start ngrok: `ngrok http 3000`
2. Copy the forwarding URL (e.g., `https://abcdef123.ngrok.app`).
3. Register this URL as your webhook endpoint in the Sandbox Developer Dashboard.
4. Trigger test transactions using the magic phone numbers to receive webhooks locally.

## Testnet Stellar Accounts

The Sandbox environment operates exclusively on the **Stellar Testnet**. 

When providing a `stellar_address` for deposits, ensure it is a valid Testnet account. The Bridge will mint test tokens to this address.

You can generate Testnet accounts and fund them with test XLM using the [Stellar Laboratory](https://laboratory.stellar.org/#account-creator?network=test).
